# Optional online AGY continuation

Codex is the primary coordinator. The user may explicitly continue with an
online AGY lead using Gemini 3.8 Flash High, then return to Codex. This is an
optional handover, not a permanent platform change or automatic quota detector.

Run `Resume Antigravity.command` to select AGY, or `Return to Codex.command` to
select the primary again. Assigned task-ID launches open that worker's own
branch/worktree without changing the coordinator. Normal permissions remain.

Read AGENTS.md, current policy/task records and repository status first. Keep
Smart disabled and importing stopped. Use synthetic fixtures and targeted checks;
do not inspect private chats, load models or manufacture ingestion work.

The active online coordinator plans and assigns bounded tasks. Use a separate
online worker context/identity for implementation, record actual check results,
review the exact candidate and integrate through the workflow. Historical task
records from private operator sessions are not part of this public release.
If no task is assigned, identify one useful function or reproducible bug within
the product scope; do not add unrelated scaffolding.
