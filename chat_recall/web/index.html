Connect the browser helper

The helper imports ChatGPT history into this local archive. Live syncing is experimental; project and archived-chat coverage require verification.

  1. Load the included browser-extension folder as an unpacked extension.
  2. Add its exact chrome-extension://… origin to the server’s extension allowlist, then restart the server.
  3. Open the helper, pair this endpoint and token, then run an initial import.

Treat this token as access to your local archive. Keep it out of Git, screenshots, and shared tasks.
